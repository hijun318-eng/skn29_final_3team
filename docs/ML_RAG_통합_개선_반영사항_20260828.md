## 핵심 결과

- ML 예측은 별도 화면 없이 기존 분석 대화의 에이전트 응답 카드로만 표시한다.
- 일반 질문을 키워드만으로 ML 또는 RAG에 자동 전환하지 않는다.
- RAG 문서는 역할, 승인 상태, 유효기간을 통과한 경우에만 검색·목록·PDF 조회를 허용한다.

## 반영 내용

### ML

- 별도 `MLPredictionWorkspace`와 전용 입력 폼 제거
- `[객실 예측]`으로 명시한 요청만 ML 실행
- 지원 호텔·기준일·예측 기간을 ML runtime capability로 검증
- 예측값·모델 버전·Trino query 근거를 기존 대화 카드에 표시

### RAG

- `requested_route=INTERNAL_GUIDELINE`인 요청만 RAG 실행
- 검색·문서 목록·PDF에 동일한 역할·승인·유효기간 필터 적용
- 빈 생성 답변을 검색 원문으로 대체하지 않고 오류 처리
- 더미 API 키와 기본 HMAC secret 제거
- 현재 역할이 열람할 수 있는 승인 문서 목록을 서버에서 동적으로 조회

## 운영 설정

- 기본값은 안전을 위해 ML·RAG 모두 비활성화한다.
- 운영 승인 후 `ML_FEATURE_ENABLED=1`, `RAG_FEATURE_ENABLED=1`을 설정한다.
- `RAG_GATEWAY_HMAC_SECRET`, `RAG_ANSWER_API_KEY`, `RAG_ANSWER_ENDPOINT`는 Secret으로 주입한다.

## 검증 결과

- 프론트 테스트 24개 통과
- 프로덕션 빌드 성공
- 저장소 무결성 감사 1,144개 파일 통과
- Python 변경 파일 구문 검사 및 Compose 설정 검사 통과
- 전체 백엔드 pytest는 로컬 환경에 pytest가 없어 실행하지 못함
- RAG live E2E에서 검색·답변·인용 17/17, 멀티턴·HMAC 보안 검증 통과
- 96문항 reranker A/B에서 BGE v2-m3만 사전 합격 기준 통과
