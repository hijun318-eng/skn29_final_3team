# 20260728 데일리 스크럼

> 팀원 5명의 개인 일일보고를 바탕으로 만든 발표 초안이다.

## 오늘 팀 진행 상황

- 멘토링 의견을 반영해 서비스 방향과 개발 범위를 다시 정리했다.
- 데이터 구조, 안전한 분석 과정, 역할별 작업 기준을 구체화했다.
- Answervice 화면 목업과 화면설계서를 현재 기획에 맞게 개선했다.

## 팀원별 발표 메모

### 박준희 (`junhee`)

- 오늘 한 일: 데이터 연결부터 분석과 보고서 생성까지 전체 처리 흐름을 정리했다.
- 결과 및 공유: 보호해야 할 문서 목록을 복원하고 공식 문서 순서를 바로잡았다.

### 송민지 (`minji`)

- 오늘 한 일: 분석, 보고서, 데이터 목록, 연결 관리 화면을 목업으로 구현했다.
- 결과 및 공유: 보고서 편집 기능과 화면설계서를 현재 기획에 맞춰 갱신했다.

### 김재홍 (`jaehong`)

- 오늘 한 일: 업무별 데이터 목록과 데이터 간 관계를 다시 설계했다.
- 결과 및 공유: 데이터베이스 생성 기준과 합성 데이터 준비 범위를 구체화했다.

### 정승 (`seung`)

- 오늘 한 일: 데이터 관리와 자동 보고서 중심으로 서비스 방향을 정리했다.
- 결과 및 공유: 서비스명을 Answervice로 확정하고 주요 화면을 구현해 실행을 확인했다.

### 윤대성 (`daesung`)

- 오늘 한 일: 멘토링 의견을 반영해 기획서, 역할별 작업 문서, 전체 일정을 작성했다.
- 결과 및 공유: 안전한 데이터 분석 구조와 시스템 구성도를 발표용 그림으로 정리했다.
