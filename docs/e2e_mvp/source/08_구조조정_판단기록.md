# 구조조정 판단 기록

## 현재 문서 구조 결정

- `source/`에는 사용자가 제공한 원문과 구조조정 판단 기록을 둔다.
- `derived/`에는 현재 구현에 직접 필요한 PRD, 유저플로우, 아키텍처 계약, 운영 가이드와 상태 문서만 둔다.
- 특정 외부 에이전트용 작업지시서는 제품 문서 구조에서 제거한다.
- 제출 산출물과 과거 협업 문서는 사용자가 현재 요청에서 지정하지 않으면 제품 구현 근거로 사용하지 않는다.

## 유지

- `derived/01_MVP_PRD.md`
- `derived/02_Golden_Path_유저플로우.md`
- `derived/03_E2E_아키텍처_및_계약.md`
- 현재 적재 중인 `derived/service_demo_v3/` SQL·Compose·검증 파일
- Pod와 Serverless RunPod 운영 가이드
- 현재 구현과 검증 상태를 기록한 인수인계 문서
- Docker 감사 근거인 `derived/06_데이터_SQL_Web_작업지시서.md`

## 제거

- 구현이 끝난 일회성 실행 프롬프트
- 중복된 구현 순서·검증표
- 특정 외부 에이전트용 데이터 생성·재작업·자동 실행 지시서
- 현재 적재에 사용하지 않는 과거 SQL 초안

## 원칙

현재 적재에 사용하는 SQL은 보존한다. 문서 수 자체보다 현재 구현에 필요한 단일 기준이 있는지를 우선하며, 삭제된 과거 문서를 다시 늘리지 않고 PRD·유저플로우·아키텍처 계약과 현재 상태 문서를 갱신한다.
