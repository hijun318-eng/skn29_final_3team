## 폴더 역할

`docs/markdown/ai_docs/`는 공식 번호 산출물과 분리한 참고 자료 보관 위치다. 현재 참고문서는 폴더 루트에 두고 수정·삭제 전 원본은 `legacy/`에 분리한다.

- AI가 작성한 기획·검토·계약 보조 자료
- 워커힐·호텔 VOC 관련 외부 조사와 분석
- 공식 일정·교육 운영의 조회 시점 스냅샷
- 과거 통제 문서와 저장소 구조 감사 자료
- 수정·삭제 전 원본을 보존하는 `legacy/`

활성 참고문서는 빠르게 판단할 수 있는 압축본으로 유지한다. 날짜가 붙은 구현 현황, 완료된 일회성 작업 지시, 상세 조사·과거 계약·긴 표와 예시는 `legacy/`에서 보존하며 현재 사실과 범위 판단에는 사용하지 않는다. 역할 매뉴얼은 역할 경계와 역할별 검증만 유지하고 공통 작업 시작·CI·handoff·Git 절차는 `../collaboration/README.md`를 따른다.

## 사용 원칙

근거 우선순위와 공식 제출본의 참고 문서 제외 기준은 [`docs/문서관리규칙.md`](../../문서관리규칙.md)를 따른다. 이 폴더에서는 활성 압축본과 `legacy/` 이력을 분리하고, 과거 스냅샷을 현재 저장소 구조나 확정 사실로 해석하지 않는다.

## 문서 정리와 신규 문서 검토

다음 문서는 삭제·병합·요약 대상에서 제외한다.

- `최종_프로젝트_산출물_및_전체_일정.md`

그 밖의 문서는 필요에 따라 삭제하거나 다른 문서에 병합·요약할 수 있다.

`ai_docs/`에 문서 파일이 추가될 때마다 다음 검토를 진행한다.

1. 신규 문서를 위 정리 제외 문서와 기존 기준 문서에 대조한다.
2. 활성 번호 문서·코드·테스트와 상충하면 해당 활성 기준을 보존한다. 문서 기준일 비교는 같은 우선순위의 `ai_docs/` 참고문서끼리만 적용한다.
3. 상충 내용은 `docs/문서관리규칙.md`의 충돌 기록 형식으로 관련 작업 문서에 남긴다.
4. 기록 후 정리 제외 문서는 유지하고, 그 밖의 오래된 상충 내용은 명시적 정리 요청이 있을 때만 `legacy/`에 보존한 뒤 현재 경로에서 제거한다.

과거 상충 기록은 [`README_v2.1.md`](legacy/README_v2.1.md)에 보존한다.

## 원본 문서 보관

문서를 수정하거나 삭제하기 전에 원본을 `legacy/`에 보관한다.

- 수정: 수정 전 원본의 복사본을 `legacy/`에 생성한 뒤 현재 경로의 문서를 수정한다.
- 삭제: 삭제할 원본을 `legacy/`로 이동하고 현재 경로에서 제거한다.
- 파일명: 원본 파일명에 version을 붙인다. version이 없거나 이름이 겹치면 `_원본_YYYYMMDD_HHMM`을 추가한다.
- 보존: `legacy/`의 파일은 수정·삭제·병합·요약하지 않는다.
- 사용: `legacy/`는 과거 이력 전용이며 신규 문서 상충 검토와 현재 기준 문서에서 제외한다.
