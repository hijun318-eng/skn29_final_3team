| 항목 | 결정 |
|---|---|
| 프로젝트 | DataHub Core 기반 대화형 데이터 분석·자동 리포팅 서비스 `Answervice` |

| 범위 | 이번 실행의 처리 |

| P0 | 메인 챗, G1·G2·G3, 읽기 전용 Text-to-SQL, 결과·근거·차트, Chat↔Report, 수동·schedule 실행 |

모든 Wave 1 카드는 위 범위와 WBS의 `R*-**` 추적 ID에 연결한다. P2·고객 360은 현재 I1~I5 실패 조건이 아니다.
