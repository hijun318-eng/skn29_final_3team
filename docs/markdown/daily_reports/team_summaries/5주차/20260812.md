# 20260812 데일리 스크럼

## 오늘 팀 진행 상황

- 멘토링을 통해 현재 구현의 기능·시나리오 구체화가 부족하고, 일부 목업 기능이 실제 백엔드와 데이터 흐름까지 연결되지 않은 점을 확인했다.
- 화면 동작 여부에 머무르지 않고 프론트엔드 → 백엔드 → 데이터·AI까지 실제로 연결한 뒤, 기능별 요청과 응답을 확인하는 동적 검증을 강화하기로 했다.
- 복잡한 R1~R5 승인 절차를 축소해 단일 코딩 에이전트 중심의 빠른 개발·검증 방식으로 전환하고, Text-to-SQL 성능 개선을 위한 sLLM 추가 튜닝과 검증을 진행하기로 했다.
