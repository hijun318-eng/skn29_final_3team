> 상태: WORKING DRAFT

> 권위: 최종 승인 전까지 기존 제품 문서를 대체하지 않는다.

## 0. 작성 계약

이 문서는 기존 PRD의 문장을 그대로 합치는 문서가 아니다. 제품 목적부터 다시 결정한다.

- 한 번에 핵심 결정 하나만 확정한다.
- 각 결정에는 추천안, 대안, 비용·일정·품질 영향을 기록한다.
- 확인하지 않은 내용은 요구사항으로 쓰지 않고 `OPEN`으로 둔다.
- 기능은 핵심 사용자 과업, 사용자 결과, 인수 조건, E2E 증거가 모두 연결될 때만 MVP에 포함한다.
- 기술 이름이나 평가 체크리스트만으로 기능을 추가하지 않는다.
- 안전·정확성·실패의 정직성은 화면 수나 기술 시연보다 우선한다.
- 단위·mock 테스트 통과와 실제 제품 E2E 통과를 구분한다.
- 일정이 부족하면 지원 범위를 줄이고, 숨은 fallback이나 고정 정답으로 성공을 만들지 않는다.

### 상태 표기

| 상태 | 의미 |
|---|---|
| `OPEN` | 사용자 결정이 필요하다. |
| `DECIDED` | 사용자가 명시적으로 확정했다. |
| `ASSUMED` | 진행을 위한 임시 가정이며 최종 확인이 필요하다. |
| `DEFERRED` | 이번 릴리스에서 결정하거나 구현하지 않는다. |
| `OUT` | 이번 제품 범위에서 명시적으로 제외한다. |
